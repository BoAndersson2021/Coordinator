# CodeExp2 — Machine development and evidence

`MACHINE_AUTOMATED_EXECUTION_REQUIRED` governs Machine and all its adapters and
every new/edited feature. Workflow execution requires zero manual lifecycle,
communication or handover steps, with loud failures that block before effects.

This repository holds the builder mission, shared guides, reviewed candidates,
acceptance evidence and current documentation. Runtime implementation is in
Desktop/Machine. The fail-closed guard and mandatory pinned pre-commit verifier
are installed there. Automatic workflow providers remain unqualified and blocked.

Read [AGENTS.md](AGENTS.md), [onboarding](Machine/README.md),
[current mission](Machine/CURRENT_MISSION.md), [requirements](Machine/AUTOMATED_WORKFLOW_REQUIREMENTS.md)
and [documentation status](Machine/DOCUMENTATION_INDEX.md). The three guides in
docs govern build coordination, communication and lifecycle; their Machine
snapshots match the current recorded hashes. Historical manual examples and
sealed source-review packages remain archival, not current operating authority.
