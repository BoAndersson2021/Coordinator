# Design status and current invariant

`MACHINE_AUTOMATED_EXECUTION_REQUIRED` governs every implementation and adapter,
including all new/edited features. Workflow execution must require zero manual
lifecycle, communication or handover, with visible failures that block effects.
The installed guard enforces denial until automatic providers are qualified.

The three root design texts carry this current operational addendum. The frozen
agentic-game-studio-v0.2-handoff and studio-capability-system-v0.1 packages retain
their exact original bytes as specification inputs. They are not activated services
or permission to use historical manual examples. Keep unresolved mandatory
conflicts visible and block affected implementation.

Use [the invariant](../docs/WORKFLOW_INVARIANT.md), [runbook](../docs/RUNBOOK.md),
[frontier](../docs/ROADMAP.md) and [documentation index](../docs/DOCUMENTATION_INDEX.md)
for current capability and acceptance status. Lifecycle remains proposed.
