for Machine and every adapter it uses, controls or communicates with, including
every new/edited feature. Workflow execution requires zero manual lifecycle,
communication, coordinator restart or handover, with visible blocking failures.

remain unqualified. CodeExp2's pre-commit hook blocks staged changes without
reviewed verification. Its reviewed documentation-only exception is bound to an
exact parent and staged tree and grants no feature or workflow authority. Feature
changes require reviewed invariant enforcement and meaningful staged regressions.
No native app is installed.

## Preserved history — not active workflow instructions

Frozen versioned Design packages are unchanged specification inputs, not enabled
runtime services. Their original manual examples cannot override current owner
scope or the invariant. Mandatory conflicts block affected implementation; do not
silently modify frozen source or invent design approval.

Castle decisions/CASTLE_LIVE_TEST, agent-behavior and admission reports, foundation
acceptance, source-review briefs/manifests, rejected/accepted candidate snapshots,
installation backups and raw receipts/results retain their original bytes/scopes.
They record history; earlier PASS/pending/enablement text is not current readiness
or permission to use a manual fallback. Read the maintained checkpoint first.
Do not rewrite sealed evidence or its hashes to make a failed workflow look accepted.

DOCUMENTATION_SYNC/previous retains the exact prior maintained documentation.
Desktop/Machine/docs/communications/archive retains the original pinned guide
snapshot/provenance. These are explicitly archival. The synchronized guides change
current context hashes intentionally; old tasks/permits are not re-pinned, renewed,
replayed, verified or closed by documentation maintenance.

[The synchronization record](DOCUMENTATION_SYNC/RESULT.json) enumerates coverage,
current hashes, classifications and preservation checks. Future documentation and
runbook edits must preserve the same invariant and distinguish actual installed
checks from qualified automated workflow execution.
